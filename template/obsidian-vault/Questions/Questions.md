# Questions

One note per open question, and the question is the unit that drives the research. A topic is not a question: "how does the exemption work" is browsing; "does the exemption survive the 2027 sunset" is something that can be settled.

Set `status: answered` and fill `answered-by` when a question closes — closed questions are as valuable as open ones, and cheaper to lose.

Add every new note to the list below — this map is maintained by hand so the vault works with no community plugins installed. [[Dataview Queries]] mirrors it for anyone who has Dataview.
