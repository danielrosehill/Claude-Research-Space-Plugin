# Findings

Atomic claims, each citing at least one source. Titled with the claim itself — "Tariff exemption expires 2027", not "Tariff exemption" — because the title is the link text every output will use.

A finding with no `sources` is an assertion. Cite it or move it to `Notes/`.

Add every new note to the list below — this map is maintained by hand so the vault works with no community plugins installed. [[Dataview Queries]] mirrors it for anyone who has Dataview.
