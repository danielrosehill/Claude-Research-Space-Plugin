# Entities

People, organisations, products, places, events. Contacts live here too, as `entity-type: person`.

Fill `aliases` so `[[Acme]]` and `[[Acme Corporation]]` resolve to one note. Link entities to each other — this folder is what makes the graph view worth opening.

Add every new note to the list below — this map is maintained by hand so the vault works with no community plugins installed. [[Dataview Queries]] mirrors it for anyone who has Dataview.
