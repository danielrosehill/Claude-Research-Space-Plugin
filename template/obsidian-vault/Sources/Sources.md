# Sources

One note per source. Never two sources in one note — the whole point of the folder is that `reliability` and `retrieved` attach to a specific artefact.

`retrieved` records when you actually fetched it, which is not the same as when it was published, and is what tells the next reader whether it can still be trusted.

Add every new note to the list below — this map is maintained by hand so the vault works with no community plugins installed. [[Dataview Queries]] mirrors it for anyone who has Dataview.
